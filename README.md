Activity 2 – Data Structures & Algorithms

This activity focuses on solving advanced Data Structures and Algorithms (DSA) problems involving strings, trees, arrays, and searching techniques. The problems help develop efficient problem-solving and algorithmic thinking skills.

Problems Covered

1. Longest Palindromic Substring – Find the longest substring that reads the same forward and backward.


2. Implement Trie – Implement a Trie data structure to efficiently insert, search, and check prefixes of words.


3. Subarray Sum Equals K – Find the number of continuous subarrays whose sum equals a given value.


4. Search in Rotated Sorted Array – Search for a target element in a sorted array that has been rotated.


5. Minimum Window Substring – Find the smallest substring containing all characters of a given target string.



Learning Objectives

Understand advanced DSA concepts.

Implement efficient searching and string-processing techniques.

Learn the working of the Trie data structure.

Improve time and space complexity analysis.

Develop problem-solving skills using Java.


Technologies Used

Language: Java

Concepts: Strings, Arrays, Trie, Sliding Window, Hashing, Binary Search


Conclusion

This activity provides hands-on experience with important DSA problems and strengthens the ability to design efficient algorithms for complex programming challenges.
